# Prompt for Strassen's Matrix Multiplication Visualization

## Project Title

Divide-and-Conquer Matrix Multiplication using Strassen's Algorithm

## Objective

Create an educational visualization that explains Strassen's matrix multiplication algorithm and demonstrates how the Divide-and-Conquer approach can be used to multiply two square matrices efficiently. The visualization should clearly represent the recursive process, the seven intermediate products, and the construction of the final resultant matrix.

## Problem Description

Strassen's algorithm is an improved matrix multiplication technique based on Divide-and-Conquer. It divides each input matrix into four smaller submatrices and uses seven recursive multiplications instead of the eight recursive multiplications used by the basic divide-and-conquer matrix multiplication method.

## Visualization Instructions

### Stage 1: Input

Display two square matrices A and B of order n. Indicate that the matrix order should be a positive power of two for this implementation.

### Stage 2: Base Case

Show a decision block that checks whether the matrix order n equals 1. If yes, multiply the two individual elements directly and return the result. Otherwise, continue dividing the matrices.

### Stage 3: Divide

Divide each input matrix into four quadrants:

A11, A12, A21, A22

B11, B12, B21, B22

Represent the four quadrants visually using a 2 × 2 partition of each matrix.

### Stage 4: Conquer

Show the seven recursive multiplication formulas:

M1 = (A11 + A22)(B11 + B22)

M2 = (A21 + A22)B11

M3 = A11(B12 - B22)

M4 = A22(B21 - B11)

M5 = (A11 + A12)B22

M6 = (A21 - A11)(B11 + B12)

M7 = (A12 - A22)(B21 + B22)

Clearly indicate that each product is calculated recursively using smaller matrices.

### Stage 5: Combine

Display the four formulas used to construct the resultant matrix:

C11 = M1 + M4 - M5 + M7

C12 = M3 + M5

C21 = M2 + M4

C22 = M1 - M2 + M3 + M6

Show how these four result quadrants are assembled into the final matrix C.

### Stage 6: Output

Display the final resultant matrix C = A × B. Include a small example using two 2 × 2 matrices, if space permits.

### Stage 7: Complexity

Include the recurrence relation:

T(n) = 7T(n/2) + O(n²)

Show the resulting time complexity:

O(n^log2(7)) ≈ O(n^2.807)

## Design Requirements

Use a clean academic flowchart style with a white background, readable mathematical notation, clear arrows, and blue and green accents. Separate the Divide, Conquer, and Combine stages using distinct visual sections. Keep all formulas accurate and ensure that the diagram is suitable for a Data Structures and Algorithms college project.

## Expected Result

Generate a high-resolution landscape flowchart or infographic that explains the complete working of Strassen's matrix multiplication algorithm. Save the final image as Visualization.png.
